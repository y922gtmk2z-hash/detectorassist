# Design reference

The source design is the "Detectorist Map App" canvas (wireframes + 4 hi-fi
screens). Export it here (PNG/PDF per screen) so it lives next to the code.

Tokens used in `src/styles.css`:

| Token | Value |
|---|---|
| Moss green (primary) | `#1E4D3B` |
| Ink (text) | `#12211A` |
| Amber (single accent) | `#F2B632` |
| Fonts | Instrument Sans (UI), JetBrains Mono (grid refs, coordinates) |

The design's Aerial layer is deferred in v1.
